## 📌 Project Overview

This project focuses on transforming a raw Excel healthcare dataset into an interactive treatment analysis dashboard.

The original dataset contained patient recovery information, treatment details, assigned doctors, and associated treatment costs. The data was structured as a simple Excel file and required organization and transformation to make it suitable for meaningful analysis.

The goal of this project was to create a centralized analytical view that helps evaluate treatment effectiveness, cost distribution, and recovery outcomes.

---

## 📂 Dataset

The source Excel file contained patient treatment records, including:

- Recovery Score
- Treatment Type
- Doctor Name
- Treatment Cost
- Patient-related information

The dataset provided a foundation for analyzing relationships between treatment methods, healthcare costs, and recovery outcomes.

---

## 🛠️ Data Preparation & Transformation

The raw Excel dataset was cleaned and prepared for dashboard development.

Key preparation steps included:

- Reviewing and organizing raw healthcare records
- Standardizing data fields for consistent analysis
- Preparing treatment and recovery metrics
- Structuring the dataset for visualization
- Ensuring data consistency for accurate reporting

---

## 📊 Dashboard Features

The dashboard provides an overview of treatment performance and recovery trends through interactive visualizations.

Users can analyze:

- Recovery score distribution
- Treatment effectiveness
- Treatment cost analysis
- Doctor performance overview
- Comparison between treatment types

Interactive filters allow users to explore specific treatments, doctors, and recovery outcomes.

---

## 🎯 Project Goals

The dashboard was designed to:

- Provide visibility into healthcare treatment outcomes
- Identify trends between treatment types and recovery scores
- Analyze treatment costs and their relationship with recovery performance
- Enable easier exploration of healthcare data
- Convert raw records into actionable insights

---

## ✅ Outcome

The project transformed a raw Excel healthcare dataset into a structured treatment analytics solution. The final dashboard provides a clearer understanding of recovery patterns, treatment performance, and cost-related insights, enabling more efficient analysis of healthcare data.
